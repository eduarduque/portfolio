Sentinel — AI Connector Security Monitor

Scans the domains and services connected to a Claude AI setup and flags security risks in real time. Checks SSL cert expiry, missing HTTP security headers, known CVEs via the OSV vulnerability database, and GitHub supply chain signals (archived repos, suspicious commits, ownership changes). Outputs a 0–100 risk score with SAFE / LOW / MEDIUM / HIGH / CRITICAL bands.
